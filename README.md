# Google Play Store Dataset — EDA & Feature Engineering

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) and feature engineering on the Google Play Store dataset using Python. The goal is to understand app categories, ratings, installs, pricing, and app sizes to identify useful patterns and trends.

## 🎯 Project Objectives
- Identify the most popular app categories.
- Analyze app ratings, installs, and sizes.
- Explore free vs. paid applications.
- Clean the dataset and handle missing or inconsistent values.
- Perform feature engineering to prepare data for analysis.

## 📂 Dataset
The project uses Google Play Store app data containing information such as:
- App name and category
- Rating and number of installs
- App size and price
- Type, content rating, and genres

**Files included:**
- `playstore.ipynb` — Jupyter Notebook containing the analysis.
- `data/google_cleaned.csv` — Cleaned dataset in CSV format.
- `data/google_cleaned.xlsx` — Cleaned dataset in Excel format.

## 🛠️ Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## 🔍 Project Workflow
1. Data collection and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature engineering
5. Data visualization and interpretation

## 📊 Key Analysis Areas

- App ratings and installs

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/Khushi-8076/google-play-store.git
   ```
2. Open the project folder:
   ```bash
   cd google-play-store
   ```
3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn openpyxl jupyter
   ```
4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open `playstore.ipynb` and run the cells.
